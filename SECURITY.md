# Security Policy

**PLEASE DON'T DISCLOSE SECURITY-RELATED ISSUES PUBLICLY, [SEE BELOW](#reporting-a-vulnerability).**

## Reporting a Vulnerability

If you discover a security vulnerability, please report it privately through
**GitHub Private Vulnerability Reporting**: go to the repository's **Security**
tab and click **"Report a vulnerability"**. This creates a private advisory
visible only to maintainers.

All security vulnerabilities will be promptly addressed.
